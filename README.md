## 🚀 About this project

This repo powers my personal portfolio — a fast, fully responsive, single-page site built **from scratch** with plain HTML, CSS, and JavaScript (no frameworks, no bloat). It's where I showcase my data science projects, skills, and journey as a second-year B.Tech Data Science student.

> 🔗 **Live:** [bytebymayank.bio](https://bytebymayank.bio)

## ✨ Highlights

- 🎨 Custom-built logo & gradient design system
- 📱 Fully responsive — mobile, tablet, and desktop
- 🧭 Smooth-scroll navigation with active-section highlighting
